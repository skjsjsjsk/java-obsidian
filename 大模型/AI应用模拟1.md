**问题 1：Agent 基础设计**

假设你要做一个“个人知识库 Agent”，用户可以上传 PDF、Markdown、网页链接，然后用自然语言提问。Agent 需要：

- 能基于用户资料回答问题
- 能在资料不足时说明不知道
- 能调用一个搜索工具补充外部信息
- 能给出引用来源
- 支持多轮对话

请你从高层架构讲起：这个系统会包含哪些核心模块？一次用户提问从进入系统到返回答案，大致会经过哪些步骤？

**问题 2：RAG 质量问题排查**

你上线了这个个人知识库 Agent。用户反馈：  
“我明明上传了相关 PDF，但 Agent 经常答非所问，或者说找不到资料。”

你会如何排查这个问题？请从 **文档处理、索引、检索、重排、Prompt、模型生成** 这几个环节讲。

**问题 3：Agent 工具调用设计**

现在这个知识库 Agent 增加三个工具：

- search_web(query)：联网搜索
- read_document(doc_id, page)：读取指定文档页
- create_note(title, content)：把回答整理成笔记保存

请你设计一个 Agent 调用工具的流程。重点回答：

1. 模型如何知道有哪些工具、每个工具怎么用？
2. 工具调用参数怎么校验？
3. 怎么避免模型乱调用工具或重复调用工具？
4. 工具执行失败时怎么处理？
