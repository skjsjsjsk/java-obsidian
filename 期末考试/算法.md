# 2
1. 评价算法的标准: 
	1. 算法维护的 **方便性**
	2. 算法的时间成本(时间复杂度/耗费时间)
	3. 算法的空间成本(空间复杂度/占用存储)
2. 复杂度排序 `O(1)<O(logn)<O(n)<O(nlogn)<O(n2)<O(n3)<O(2n)<O(n!)<O(nn)`
3. 算法的存储量: 输入数据/ 算法本身/ 辅助变量所占空间
4. 提高算法的质量: 
	1. 保证正确性, 可靠性, 健壮性, 可读性
	2. 提高效率
