- 倒序来比较大小往数组 `nums1` 里面放
- 为什么 `if` 里面是要 `nums1` 大于 `nums2` 呢?
	- 这是因为有 `m1 >= 0` 的限制, 要求 `if` 里面判断的是 `nums1` 还存在的情况, `nums1` 里面的元素判断完就剩 `num2` 的话, 就走了 `else` 分支, 所以 `else` 分支里面必须是令 `nums2` 里面的元素到 `nums1` 里面的
```
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        int m1 = m - 1, n1 = n - 1, all = m + n - 1;
        while(n1 >= 0){
            if(m1 >= 0 && nums1[m1] > nums2[n1]){
                nums1[all] = nums1[m1];
                m1--;
                all--;
            }else{
                nums1[all] = nums2[n1];
                n1--;
                all--;
            }
        }
    }
}
```
