```
class Solution {
    public int numIslands(char[][] grid) {
        int ans = 0;
        for (int i = 0; i < grid.length; i++) {
            for (int j = 0; j < grid[i].length; j++) {
                if (grid[i][j] == '1') {
                    dfs(grid, i, j);
                    ans++;
                }
            }
        }
        return ans;
    }
	
	// 深度遍历, 先判断是否符合条件, 符合就修改当前位置的值, 使得它不等于1, 代表已经遍历过了, 不符合就退出. 然后继续递归遍历直到结束
    private void dfs(char[][] grid, int i, int j){
        if(i<0 || i>=grid.length || j<0 || j>=grid[0].length || grid[i][j]!='1') return;
        grid[i][j] = '2';
		
		// 上下左右四个方向全部遍历完毕
        dfs(grid, i-1, j);
        dfs(grid, i+1, j);
        dfs(grid, i, j+1);
        dfs(grid, i, j-1);
    }
}
```
- 时间复杂度为O(mn). 其中 m 和 n 分别是 grid 的行数和列数. 因为dfs里面修改了已访问过位置的值, 当再次访问时, 会因为`grid[i][j]!='1'`这个条件不满足直接退出递归, 所以最多插上mn个🚩, 就需要O(mn)时间
- 空间复杂度O(mn)
