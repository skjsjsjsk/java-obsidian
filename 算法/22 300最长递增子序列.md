- 递推
- 创建一个数组出来记录已 nums[i] 结尾的最长子序列有多长
```
class Solution {
    public int lengthOfLIS(int[] nums) {
        int n = nums.length, res = 0;
        int[] index_length = new int[n];
        for(int i=0; i<n; i++){
            for(int j=0; j<i; j++){
                if(nums[j] < nums[i]){
                    index_length[i] = Math.max(index_length[i], index_length[j]);
                }
            }
            res = Math.max(res, ++index_length[i]);
        }
        return res;
    }
}
```

- 动态规划, 设 `dp[i]` 为已 `nums[i]` 结尾的最长子序列的长度
- `index_length` 这个数组用来做记忆的,  比如 `[10,9,2,5,3,7]` 这个数组, 当你为5的时候, 会跳到2, 然后下一次到3的时候, 又会跳到2计算一次2, 那么就可以把这些情况存储下来, 下次如果有值直接返回结果即可
```
class Solution {
    public int lengthOfLIS(int[] nums) {
        // 动态规划, dp[i] 代表已nums[i]结尾的最长子序列的长度, 如果它前面有比它还小的数, 那么就是dp[i] = dp[j] + 1

        // 首先定义一个数组来存储长度, 防止重复计算路径
        int[] index_length = new int[nums.length];
        int res = 0; // 存储结果
        for(int i=0; i<nums.length; i++){
            res = Math.max(res, dp(i, nums, index_length));
        }
        return res;
    }

    private int dp(int i, int[] nums, int[] index_length){
        // 先判断是否已经计算过了
        if(index_length[i] != 0){
            return index_length[i];
        }
        
        // 记录当前节点的长度
        int res = 0;
        for(int j=0; j<i; j++){
            if(nums[j] < nums[i]){
                res = Math.max(res, dfs(j, nums, index_length));
            }
        }
        res+=1;
        return index_length[i] = res;
    }
}
```
