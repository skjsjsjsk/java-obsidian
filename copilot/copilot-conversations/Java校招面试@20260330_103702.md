  - 独占线程记录

### 4. MySQL 隔离级别、可重复读、MVCC、加什么锁解决、死锁
这块是高频中的高频。

主要要答清楚：
- 四种隔离级别
  - 读未提交、读已提交、可重复读、串行化
- 可重复读的实现原理
  - 一致性读靠 MVCC
  - 当前读靠锁
- MVCC 核心
  - undo log
  - Read View
  - 版本链
- “可重复读需要加什么锁解决”
  - 如果面试官指的是“幻读怎么解决”
  - 应该答：当前读场景下通过 Next-Key Lock（记录锁 + 间隙锁）解决
  - 快照读主要依靠 MVCC 保证可重复读
- 死锁问题
  - 死锁产生原因
  - InnoDB 检测与回滚
  - 如何规避

这里很容易被追问：
- 快照读和当前读区别
- RR 为什么还能防幻读
- RC 和 RR 的 Read View 区别
- 唯一索引和非唯一索引的加锁差异
- 什么操作会触发间隙锁

### 5. Redis 线程模型、为什么单线程、分布式锁 setnx
重点一般是：
- Redis 线程模型
  - 命令执行单线程
  - 网络 I/O 在新版本中的多线程辅助
- 为什么单线程还快
  - 内存操作
  - 避免线程切换和锁竞争
  - 数据结构高效
  - I/O 多路复用
- 分布式锁 setnx
  - 基本用法：SET key value NX EX
  - 为什么不能只用 setnx
  - 锁误删、超时、续期、原子释放
  - Lua 脚本保证删除锁的原子性

容易追问：
- Redis 真的是单线程吗
- 分布式锁会有什么问题
- Redisson 的实现思路
- 主从切换下分布式锁会不会出问题
