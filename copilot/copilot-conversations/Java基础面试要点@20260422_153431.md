- 尾部插入：如果容量足够，均摊下来可以认为是 $O(1)$

这个说法在面试里也容易被追问。

> LinkedList 在已知节点位置时，插入和删除是 $O(1)$；

- 插入新元素前，先判断当前底层数组是否还能容纳新元素
- 如果不能，就进行扩容

### 2. 扩容不是永远固定“原来 1.5 倍”
常见情况可以这么说：
- 新容量通常扩成旧容量的 1.5 倍
- 但如果一次性要插入很多元素，可能直接扩到“足够容纳新元素”的大小
- 本质是取“1.5 倍容量”和“实际所需最小容量”中的较大值

面试里你不用背源码细节到每一行，但最好知道这个逻辑。

### 3. 第一次添加元素时的细节

## 五、正确做法是什么

如果是把 `LinkedList` 转成 `ArrayList`，常见写法是：

```java
LinkedList<String> linkedList = new LinkedList<>();

```

这个才是标准写法。

因为：
- `ArrayList` 有一个构造方法可以接收 `Collection`
- `LinkedList` 实现了 `List`，也属于 `Collection`
- 所以可以直接传进去构造新的 `ArrayList`

### 如果你非要先转数组，也不是不行
理论上你可以先：
```java
Object[] arr = linkedList.toArray();
```
再手动放进 `ArrayList`，但这明显不如直接：

```java
new ArrayList<>(linkedList)
```

来得简洁自然。

所以面试里最好答：

> `LinkedList` 转成 `ArrayList` 可以直接使用 `ArrayList` 的构造方法，传入一个 `Collection`，比如：`new ArrayList<>(linkedList)`。
