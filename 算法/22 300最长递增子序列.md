- 递推
- 创建一个数组出来记录已 nums[i] 结尾的最长子序列有多长
- 时间复杂度: O(n2)，其中 n 为 nums 的长度。
- 空间复杂度: O(n)
```
class Solution {
    public int lengthOfLIS(int[] nums) {
        int n = nums.length, res = 0;
        int[] index_length = new int[n];
        for(int i=0; i<n; i++){
            for(int j=0; j<i; j++){
                if(nums[j] < nums[i]){
                    index_length[i] = Math.max(index_length[i], index_length[j]);
                }
            }
            res = Math.max(res, ++index_length[i]);
        }
        return res;
    }
}
```

- 动态规划, 设 `dp[i]` 为已 `nums[i]` 结尾的最长子序列的长度
- `index_length` 这个数组用来做记忆的,  比如 `[10,9,2,5,3,7]` 这个数组, 当你为5的时候, 会跳到2, 然后下一次到3的时候, 又会跳到2计算一次2, 那么就可以把这些情况存储下来, 下次如果有值直接返回结果即可
- 时空复杂度同上
```
class Solution {
    public int lengthOfLIS(int[] nums) {
        // 动态规划, dp[i] 代表已nums[i]结尾的最长子序列的长度, 如果它前面有比它还小的数, 那么就是dp[i] = dp[j] + 1

        // 首先定义一个数组来存储长度, 防止重复计算路径
        int[] index_length = new int[nums.length];
        int res = 0; // 存储结果
        for(int i=0; i<nums.length; i++){
            res = Math.max(res, dp(i, nums, index_length));
        }
        return res;
    }

    private int dp(int i, int[] nums, int[] index_length){
        // 先判断是否已经计算过了
        if(index_length[i] != 0){
            return index_length[i];
        }
        
        // 记录当前节点的长度
        int res = 0;
        for(int j=0; j<i; j++){
            if(nums[j] < nums[i]){
                res = Math.max(res, dfs(j, nums, index_length));
            }
        }
        res+=1;
        return index_length[i] = res;
    }
}
```

- 优化, 改为使用了贪心加二分查找, 时间复杂度降低到 `O(n log(n))`
- 想法就是, 遍历给你的数组nums, 然后创建一个空的数组 g, 每一步替换都是把nums里面的小的数字重新写到g里面, 如下图这样子.  遍历完之后g的长度就是最长递增子序列

- 对于`ArrayList`来说, 长度用 `size()` , 添加元素用 `add()` , 替换元素用 `set(index, element)` , 得到元素用 `get()`.
```class Solution {
    public int lengthOfLIS(int[] nums) {
        List<Integer> g = new ArrayList<>();
        for(int i: nums){
            // 首先通过二分查找找到要替换的那个数的下标
            int j = binarySearch(g, i);
            // 然后判断要替换的位置是否已经超出了g的长度
            // 超出了就添加到子序列的末尾
            // 没有超出就把g.get(j) 替换为 i
            if(j >= g.size()){
                g.add(i);
            }else{
                g.set(j, i);
            }
        }
        return g.size();
    }

    private int binarySearch(List<Integer> g, int target){
        int left = 0, right = g.size() - 1;
        while(left <= right){
            int mid = left + (right - left) / 2;
            if(g.get(mid) < target){
                left = mid + 1;
            }else{
                right = mid - 1;
            }
        }
        return left;
    }
}
```
