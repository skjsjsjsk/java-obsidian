- 第一种, 使用两个数组
```
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        if(root == null) return List.of(); // 如果是空就返回空数组
        List<List<Integer>> ans = new ArrayList<>();
        // 先把根节点放进去
        List<TreeNode> cur = List.of(root);

        // 接下来开始判断
        while(!cur.isEmpty()){

            // 每一轮都用来存储当前的每行元素然后把这个数组添加到ans中
            List<Integer> vals = new ArrayList<>();
            // nxt用来存储下一层节点的值, 用来在这轮循环的最后替换cur, 然后开始下一轮
            List<TreeNode> nxt = new ArrayList<>();

            for(TreeNode node: cur){
                // 把当前节点的值存储在vals中, 每次循环里面都是当前这层的元素
                vals.add(node.val);
                if(node.left != null) nxt.add(node.left);
                if(node.right != null) nxt.add(node.right);
            }

            // 此刻存储好了当前这层的元素
            ans.add(vals);

            // 接下来要把cur重新变成一个空数组进入新一个轮回
            cur = nxt;
        }
        return ans;
    }
}
```

- 第二种, 使用队列, 队列是先进先出的, Java中的队列常用的有LinkedList和ArrayDeque
- 创建方式
```
Queue<TreeNode> queue = new LinkedList<>();
Queue<TreeNode> queue = new ArrayDeque<>();
```
- 
```
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        if(root == null) return List.of();
        List<List<Integer>> ans = new ArrayList<>();
        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.add(root);
        
        // 接下来开始判断
        while(!queue.isEmpty()){
            int len = queue.size();
            // 每一轮都用来存储当前的每行元素然后把这个数组添加到ans中
            List<Integer> vals = new ArrayList<>(len);

            for(int i = 0; i < len; i++){
                TreeNode node = queue.poll();
                // 把当前节点的值存储在vals中, 每次循环里面都是当前这层的元素
                vals.add(node.val);
                if(node.left != null) queue.add(node.left);
                if(node.right != null) queue.add(node.right);
            }

            // 此刻存储好了当前这层的元素
            ans.add(vals);
        }
        return ans;
    }
}
```
