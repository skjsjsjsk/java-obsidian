---

- 重载（Overload）：
	- 发生在**同一个类中**，方法名相同，但**参数列表不同**（参数个数、类型、顺序不同）。
	- 与**返回值无关**，仅仅返回值不同不构成重载。
	- 构造方法也可以构成重载，比如无参构造和有参构造。

- 重写（Override）：
	- 发生在**父子类之间**，子类对父类的方法进行重新实现。
	- 方法名、参数列表必须相同。
	- 返回值类型要相同，或者是其子类（协变返回类型）。
	- 子类方法的访问权限**不能比父类更严格**。
	- 子类重写方法**不能抛出比父类更大的检查异常**。
	- `static`、`final`、`private` 方法不能被重写。
	- `static` 方法只能被隐藏，不能被重写。

---

- “其他所有的都相同”不严谨

- 访问修饰符也不一定完全相同  
  例如父类是 `protected`，子类可以重写成 `public`。
- 异常声明也有规则，不是“所有都相同”。

**ai**: 可以这样理解：

- is-a：**是一个**
- has-a：**有一个**

它们描述的是类和类之间不同的关系。

---

### 1. is-a
表示**继承关系**，也就是“子类是父类的一种”。

比如：

- Dog is a Animal
- Cat is a Animal

Java 里一般体现为：

```java
class Animal {
}

class Dog extends Animal {
}
```

这里 `Dog` 是 `Animal` 的一种，所以这是 **is-a** 关系。

面试里可以说：

- is-a 表示继承关系
- 子类属于父类的一种更具体的类型
- 满足里氏替换原则时，父类出现的地方可以用子类替代

---

### 2. has-a
表示**组合 / 聚合关系**，也就是“一个类拥有另一个类作为成员”。

比如：

- Car has a Engine
- Person has a Address

Java 里一般体现为成员变量：

```java
class Engine {
}

class Car {
    private Engine engine;
}
```

这里 `Car` 里有一个 `Engine` 对象，所以这是 **has-a** 关系。

面试里可以说：

- has-a 表示一个类包含另一个类
- 一般通过成员变量来体现
- 属于组合或聚合思想，比继承更灵活

---

### 3. 两者区别
| 区别 | is-a | has-a |
| --- | --- | --- |
| 含义 | 是一个 | 有一个 |
| 关系 | 继承 | 组合/聚合 |
| 实现方式 | `extends` / `implements` | 成员变量 |
| 耦合性 | 更强 | 更灵活 |

---

### 4. 你笔记里那句有点问题
你之前写的是：

- 抽象类是 is-a 的关系
- 接口是 has-a 的关系

这句话**不准确**。

更准确地说：

- 类继承抽象类，通常体现的是 **is-a**
- 类实现接口，更多表示“具备某种能力”，本质上也更接近一种 **行为规范**
- has-a 一般不是指接口，而是指“成员包含关系”

比如：

```java
class Bird extends Animal implements Flyable {
}
```

这里：

- `Bird extends Animal` 是 **is-a**
- `Bird implements Flyable` 表示 `Bird` 具有飞行能力
- 如果 `Bird` 里有一个 `Wing` 成员变量，那才是 **has-a**

---

### 5. 面试简洁回答版
你可以直接背这个：

- is-a 表示继承关系，意思是“子类是父类的一种”，比如 `Dog is a Animal`。
- has-a 表示包含关系，意思是“一个类拥有另一个类作为成员”，比如 `Car has a Engine`。
- 一般来说，继承体现 is-a，成员组合体现 has-a。

**ai**: 你这段整体意思**基本对**，但有一个表述不太准确：

- “把池里的引用赋给 `a`”  
这里应该是赋给**变量 `s`**，不是赋给 `"a"`。

我帮你改成更准确、适合放进 [[Java SE]] 的版本：

---

- `String s = "a"` 和 `String s = new String("a")` 的区别：
	- `String s = "a"`：
		- 这种方式是**直接赋值**。
		- Java 会先到**字符串常量池**中查找是否已经存在 `"a"`。
		- 如果存在，就直接把常量池中 `"a"` 的引用赋给变量 `s`；
		- 如果不存在，就先在常量池中创建 `"a"`，再把它的引用赋给 `s`。
	- `String s = new String("a")`：
		- Java 会先检查字符串常量池中是否有 `"a"`。
		- 如果没有，会先在常量池中创建 `"a"`。
		- 然后再在**堆内存**中创建一个新的 `String` 对象，并把这个堆中的对象引用赋给变量 `s`。
		- 所以这种写法通常会创建**两个对象中的一个或两个**：
			- 如果常量池里已经有 `"a"`，只会在堆中再创建一个新对象；
			- 如果常量池里没有 `"a"`，则会先在常量池创建一个，再在堆中创建一个。

- 区别总结：
	- 直接赋值 `"a"` 优先复用字符串常量池中的对象，更节省内存。
	- `new String("a")` 一定会在堆中创建新的 `String` 对象，开销更大。
	- 因此开发中如果没有特殊需求，一般优先使用 `String s = "a"`。

---

再补一个面试很爱追问的点：

```java
String s1 = "a";
String s2 = "a";
System.out.println(s1 == s2); // true

String s3 = new String("a");
String s4 = new String("a");
System.out.println(s3 == s4); // false
```

原因是：

- `s1` 和 `s2` 都指向字符串常量池中的同一个对象
- `s3` 和 `s4` 是两个不同的堆对象

但：

```java
System.out.println(s3.equals(s4)); // true
```

因为 `equals` 比较的是内容。

**ai**: 你这个知识点如果写到 [[Java SE]] 里，建议不要只写一句“Java是值传递”，因为太短了，面试官一定会追问。  
我帮你整理成一版**准确+适合面试**的笔记。

---

- 值传递与引用传递：
	- Java 中**只有值传递，没有引用传递**。
	- 所谓值传递，就是在方法调用时，会把实际参数的一个副本传递给方法形参，方法内部对形参的修改不会影响外部变量本身。

- 基本数据类型的值传递：
	- 对于 `int`、`double`、`char` 等基本数据类型，传递的是具体的数值副本。
	- 方法内部修改形参的值，不会影响原来的实参。

```java
public class Test {
    public static void main(String[] args) {
        int a = 10;
        change(a);
        System.out.println(a); // 10
    }

    public static void change(int x) {
        x = 20;
    }
}
```

- 引用数据类型的值传递：
	- 对于对象、数组等引用数据类型，传递的不是对象本身，而是**引用的副本**，本质上仍然是值传递。
	- 也就是说，方法中拿到的是地址值的副本，副本和原引用都指向同一个对象。
	- 因此，如果在方法内部通过这个引用去修改对象的成员属性，外部是可以看到变化的。
	- 但如果在方法内部让形参重新指向一个新对象，不会影响外部原来的引用。

```java
class Person {
    String name;
}

public class Test {
    public static void main(String[] args) {
        Person p = new Person();
        p.name = "张三";
        changeName(p);
        System.out.println(p.name); // 李四
    }

    public static void changeName(Person person) {
        person.name = "李四";
    }
}
```

- 上面这个例子中，虽然 `p` 的值传递给了 `person`，但它们指向的是同一个对象，所以修改对象属性后，外部能看到变化。

- 重新指向新对象不会影响原引用：

```java
class Person {
    String name;
}

public class Test {
    public static void main(String[] args) {
        Person p = new Person();
        p.name = "张三";
        change(p);
        System.out.println(p.name); // 张三
    }

    public static void change(Person person) {
        person = new Person();
        person.name = "李四";
    }
}
```

- 这里 `person` 只是接收了 `p` 的引用副本。
- 当执行 `person = new Person()` 时，只是让 `person` 指向了一个新的对象，不会影响外部的 `p`。

- 总结：
	- Java 中没有引用传递，只有值传递。
	- 基本类型传递的是具体的值。
	- 引用类型传递的是引用地址的副本。
	- 修改引用指向对象的内容会影响原对象；
	- 修改引用本身的指向不会影响原引用。

---

你面试时可以简洁回答成这样：

- Java 只有值传递。
- 如果传的是基本类型，传递的是值的副本，方法内修改不会影响外部变量。
- 如果传的是引用类型，传递的是引用地址的副本，两个引用会指向同一个对象，所以修改对象内部状态会影响外部；但如果让形参指向新对象，不会影响原引用。
