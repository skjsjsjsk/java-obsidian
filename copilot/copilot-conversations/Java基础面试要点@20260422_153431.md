## 一、这题正确的核心答案是什么

面试官问“为什么要把基本数据类型做成包装类”，核心要答这几个点：

- Java 是面向对象语言，基本数据类型不是对象，但很多场景需要对象参与
- 集合类只能存对象，不能直接存基本类型
- 泛型要求类型参数必须是引用类型，不能是基本类型
- 包装类提供了很多实用方法，比如类型转换、字符串转换、比较、常量值等
- 包装类支持自动装箱和拆箱，提升了使用便利性
- 有些场景需要用 `null` 表示“没有值”，基本类型做不到，包装类可以

## 二、你这次回答错在哪里

### 1. “可以检查写入的数据类型是否正确”

类型检查主要是 Java 的类型系统、编译器、泛型机制在做，不是“因为有包装类所以才能检查”。

比如：
- `int` 本身也有类型检查
- `Integer` 也有类型检查

### 2. “编译的时候都会被还原为 Object”

比如：
```java

```
这里本质上是：
```java
Integer x = Integer.valueOf(1);
```
不是“还原为 Object”。

## 四、你最好补充的两个高频点

### 1. 自动装箱和拆箱
这是面试官很喜欢顺手追问的。

你可以补一句：

> 比如 `Integer a = 10;` 是自动装箱，本质上会调用 `Integer.valueOf(10)`；  
> `int b = a;` 是自动拆箱，本质上会调用 `a.intValue()`。

### 2. Integer 缓存机制
这个也是包装类常见追问。

比如：
```java
Integer a = 127;
Integer b = 127;
System.out.println(a == b); // true

Integer c = 128;
Integer d = 128;
System.out.println(c == d); // false
```

原因是：
- `Integer` 默认缓存范围是 `-128 ~ 127`
- 这个范围内通过 `valueOf()` 返回的是同一个对象
- 超出范围会新建对象
