# Function Calling, MCP和Skill
- Function Calling: 其实就是一个JSON对象, 对AI如何使用工具, 如何回复做了标准化的定义, 让大模型可以调用工具来解决问题
- MCP: 因为Funciton Calling 对于不同的厂家来说有不同的规范, 导致同一个工具对于不同的大模型都要重写一遍. 为了解决这个, 就出现了MCP, 它是一个标准化的接入协议, 按照MCP的规范去写工具, 一次写入可以被所有大模型调用
- 流程使用MCP的: 
	- 用户请求 -> MCP Client 收到请求, 按照MCP格式把 `问题和工具列表` 打包给大模型 -> 大模型决定调用哪个工具, 生成指令(按照MCP规范) -> MCP Client 解析指令, 调用MCP Server的工具 -> 执行结果按MCP格式返回给大模型
