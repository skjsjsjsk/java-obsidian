- 想法, 使用一个哈希表去存储数组里的元素, key为元素值, value为下标, 只需要全部遍历完整个数组即可找到那一对值
```
class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<> ();
        for(int i = 0; i < nums.length; i++){
            int otherKeys = target - nums[i];
            // 接下来判断哈希表里面是否存在该值
            if(map.containsKey(otherKeys)){
                return new int[] {i, map.get(otherKeys)};
            }
            map.put(nums[i], i);
        } 
        return new int[] {};
    }
}
```
