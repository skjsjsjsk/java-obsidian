# 1 图像的文件格式有: BMP, JPEG, GIF, TIFF, PNG等
---
   1. TIFF: 是一种灵活且高质量的光栅图像格式, 广泛用于专业图像处理, 印刷, 摄影 和 文档存档等领域
	   1. 支持高质量无损压缩, 也可以选择有损压缩(如JPEG)
	   2. 多颜色模式和位深度(即RGB, MYK多种颜色模式; 位深度灵活: 8, 16, 32 甚至更高位)
	   3. 多页存储能力(就是单个TIFF文件可包含多页图像)
	    ![](assets/数字图像处理/file-20260624162132916.png)
2. JPEG: 是一种有损压缩格式, 能够将图像压缩在很小的储存空间, 图像中重复或不重要的资料会被丢失, 因此容易造成图像数据的损伤
	1. 有损压缩
	2. 适合摄影图像, 不适合线条图, 文字 或 大面积纯色区域(可能会产生块状伪影)
	3. 广泛兼容, 所有浏览器, 操作系统 和 图像处理软件都支持JPEG
	4. 颜色深度与模式, 支持24位真彩色, 不支持透明度
3. PNG: 无损压缩方式, 减少文件的大小保证最不失真的格式, 存贮形式丰富, 兼有GIF 和 JPG的色彩模式; 能把图像文件压缩到极限以利于网络传输, 又能保留有与图像品质相关的信息
4. GIF: 分为静态GIF 和 动画GIF两种, 支持透明背景图像, 适用于多种操作系统, "体型" 很小, 网上很多小动画都是GIF格式. 其实GIF是将多幅图像保存为一个图像文件, 从而形成动画, 所以归根到底GIF仍然是图片文件格式
5. BMP: Windows系统下的标准位图格式, 结果简单, 未经过**压缩**, 图像文件比较大, 适用于**科研与医学成像(要保留原数据的场景)**

# 6 频域滤波
![400](assets/数字图像处理/file-20260626120606828.png)
![400](assets/数字图像处理/file-20260626120630346.png)
**下面是求题目3的, 只到了2D-DEF这一步**
- 步骤1: 中心化操作(乘以 `(−1)^x+y`) 目的就是把频域的低频分量移至图像中心, 便于滤波器的设计
  该题的矩阵是 `2*2` 的, 所以 `x, y` 从0开始, 也就是: 
  - 当x=0, y=0, `(-1)^(0+0) = 1`, g(0,0)=5×1 = 5
  - 当 x=0,y=1, `(−1)^(0+1) = −1`, g(0,1)=0×(−1) = 0
  - 后两个也一样, g(1,0) = 0, g(1, 1) = 5
    ![400](assets/数字图像处理/file-20260626121314333.png)
- 步骤2: 计算2D-DET, 逆傅里叶变换就是把f`(x, y) 换成 F(x, y), exp里面的 - 号去掉
  ![400](assets/数字图像处理/file-20260626121659510.png)
  其中的N=2(矩阵大小), u,v∈{0, 1}.  下面就是把u,v的值带进去, 然后遍历x, y
  - u=0, v=0时, exp(0)=1, 故 `F(0, 0) = 1/2​ * [5⋅1 + 0⋅1 + 0⋅1 + 5⋅1] = 1/2​⋅10=5`
  - u=0, v=1时, exp(-jπy), 这时候就要看y的取值了, y∈{0, 1}, 当y=0时, exp(0)=1, 当y=1时, exp(-jπ)=-1, 所以 `F(0, 1) = 1/2 * [5⋅1 + 0⋅(−1) + 0⋅1 + 5⋅(−1)] = 0`
  - u=1, v=0时, 一样, `F(1, 0) = 0`
  - u=1, v=1时, `F(1, 1) = 1/2 * [5⋅1 + 0*(-1) + 0*(-1) + 5*1] = 5`
**这是高斯低通滤波器**, D(u, v)就是频率点到中心点的距离, 用来去除噪声, 平滑图像的
![400](assets/数字图像处理/file-20260626130357211.png)

**下面这是高斯高通滤波器**, 在频率域中，图像中的边缘和灰度的陡峭变化对应于傅立叶频谱的高频部分，选择能使高频通过、使低频衰减的转移函数，就可以实现高通滤波，达到**突出图像的高频边缘成分**，实现图像增强的效果。

# 8 彩色图像处理
目前常用的彩色模型可分为两类: 
1. 面向彩色监视器, 彩色视频摄影机 和 彩色打印机的硬件设备
   面向硬件设备的彩色模型主要有RGB模型, CMY模型 和 CMYK模型(用于印刷行业)
   RGB模型主要用于彩色监视器 和 彩色视频摄影机; CMYK主要用于彩色打印机
2. 面向彩色动画图像创作等的彩色处理应用
   面向彩色处理应用的模型主要是HSI模型
RGB基于三原色, 是模拟人眼视觉特性的; HSV更偏向于人类对颜色的感知方式; YUV用于视频传输, 比如电视信号; CMYK用于印刷

这里高斯滤波也比较适用于高斯噪声, 但是它对于图像边缘的保留能力更好, 因为它是通过权重去变化的, 离中心越近权重越大
