- 思路: 全排列这种, 就是一个一个从数组里面选一个数出来, 然后放到一个新的列表里面, 放满就放到结果数组里面
- 想法就是, 定义一个Boolean数组用来记录哪一个数已经被投递过, 防止重复投递; 定义一个path来临时保存当前经过的数组路径, 定义一个result数组来返回结果;
- ![500](assets/15%2046%20全排列/file-20260420215001148.png)
- 它可以拆解成这种图的结构, 所以就使用深度优先遍历去解决该问题
- dfs函数里面需要传入一个depth这么一个值, 用来判断当前是否已经遍历到底了. 
- 每次进入该方法都要先判断是否遍历完成了, 
	- 如果完成了, 就把它放到result里面`(注意要放副本)`. 
	- 如果没有, 就判断当前值是否已经被使用过了, 如果没有就放到path里面, 同时把它在used里的状态改成true, 然后继续递归直到第一次path = [1, 2, 3];
	- `i=0, path=[1], dfs -> i=1, path=[1, 2], dfs -> i=2, path=[1, 2, 3], dfs -> 此时该次dfs进来了, 由于depth==nums.length, 所以直接返回, 到了上一步的末尾 -> 这时候的状态为 i=2, path=[1, 2, 3]. 执行上一步used[i] = false和path.remove(path.size() - 1). 此时该层for循环结束, 返回第二层 -> 这时候的状态为 i=1, path=[1, 2]. 接下来执行完used[1]=false, path.remove后, 进入了for循环, 令i++ 等于了2, 然后发现used[2]=false, 添加进去, 就生成了path=[1,3], 然后进去了dfs, 先判断depth=2 不等于nums.length, 然后重新开始for循环, 从i=0 ----- i=2, 发现只有used[1] = false, 所以放到了path 里面, 令 path = [1,3,2]`

```
class Solution {
    public List<List<Integer>> permute(int[] nums) {
        boolean[] used = new boolean[nums.length];
        List<Integer> path = new ArrayList<>();
        List<List<Integer>> result = new ArrayList<>();
        dfs(nums, used, path, result, 0);
        return result;
    }
    private void dfs(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> result, int depth){
        if(depth == nums.length){
            result.add(new ArrayList<Integer>(path));
            return;
        }
        for(int i = 0; i < nums.length; i++){
            if(!used[i]){
                path.add(nums[i]);
                used[i] = true;
                dfs(nums, used, path, result, depth + 1); 
                used[i] = false;
                path.remove(path.size() - 1);
            }
        }
    }
}
```
