## 第一种, 自己当栈
- `toCharArray` 这个方法是把一个字符串变为char类型的
- 因为该题括号要匹配, 所以s的长度一定是偶数, 奇数直接false
- 接下来就把char当作一个栈, 设一个变量 `index` 作为指针初始指向栈顶
- 举个例子 `([])`
	- 首先匹配 `'('` , 令 `char[0]=')'` , index=1;
	- 然后匹配 `'['`, 令 `char[1]=']'` , index=2;
	- 接下来到了 `']'`, 转到了 else if 分支上, 先看 index 是否等于0, 等于就说明结束了, 不等于0, 那么就把当前的 `index` 指针往上移一位, 令 `index=1` , 看是否有相同的括号, 不断循环
```
class Solution {
    public boolean isValid(String s)
    {
        //如何设计一个栈 可进可退的那种 我觉得会好一点
        if(s.length()%2!=0) return false;
        char[] ch=s.toCharArray();
        int index=0;
        for(char i:ch){
            if(i=='(')  ch[index++]=')';
            else if(i=='{') ch[index++]='}';
            else if(i=='[') ch[index++]=']';
            else if(index==0||ch[--index]!=i)   return false;
        }
        return index==0;
    }
}
``` 

## 创建一个栈来做
```
class Solution {
    public boolean isValid(String s) {
        if(s.length() % 2 != 0){ // s长度必须为偶数
            return false;
        }
        // 接下来定义一个Map去映射左右括号
        Map<Character, Character> map = new HashMap<>() {
            {
                put(')', '(');
                put(']', '[');
                put('}', '{');
            }
        };
        Deque<Character> deque = new ArrayDeque<>();
        for(char c : s.toCharArray()){
            // 不是右括号就入栈
            if(!map.containsKey(c)){
                deque.push(c); 
            }else if(deque.isEmpty() || deque.pop() != map.get(c)){
                return false;
            }
        }
        return deque.isEmpty();
    }
}
```
